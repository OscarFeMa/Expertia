# Créditos cloud para startups (sin ceder equity)

Comparativa honesta 2026 (verificar cifras en cada web al solicitar, cambian):

| Programa | Tope aprox. | Requisitos típicos | Esfuerzo | Estado |
|---|---|---|---|---|
| Microsoft Founders Hub | hasta 150k$ Azure | startup <7 años, web, LinkedIn fundadores | 1-2h formulario | TODO |
| Google for Startups Cloud | hasta 100-350k$ (por tramos) | startup tech, web, entrevista ligera | 1-2h + call | TODO |
| AWS Activate | 1k-100k$ | startup + deck básico | 1h | TODO |
| OVHcloud Startup | créditos + soporte | startup europea | 1h | TODO |

Estrategia: solicitar los 4 en la misma semana con el mismo one-pager
(ver `one-pager.md`). Uso previsto: entrenos pico (4090/H100 por horas),
nunca 24/7 (eso sigue local, gratis). 10k$ equivalen a ~30.000h de 4090 spot:
una década de nuestros fine-tunes.

Checklist por solicitud:
- [ ] web o perfil público del proyecto (HF cubre esto)
- [ ] deck/one-pager 1 página
- [ ] email fundador + LinkedIn
- [ ] no ceder nada: son créditos, no inversión
